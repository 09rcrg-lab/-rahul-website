# Rahul Live

Rahul Live is a real-time Voice Room and Live Chat platform built with:

- Cloudflare Workers
- Cloudflare D1 Database
- HTML
- CSS
- JavaScript
- Progressive Web App (PWA)

## Features

- Login
- Register
- User Profile
- Live Voice Rooms
- Personal Chat
- Friends
- Follow System
- Wallet
- Coins
- Gifts
- VIP
- Recharge
- Withdraw
- Notifications
- Reports
- Helpline
- Admin Panel
- Super Admin Panel
