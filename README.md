# Rahul Live 🎙️

Lama-style Live Voice Chat Room website.

## Features

- Live voice room
- Numbered voice seats
- Empty and occupied seats
- User profile photo
- Personal chat
- Room chat
- Gifts and reactions
- Microphone controls
- Speaker controls
- Profile
- Settings
- Cloudflare Worker API
- Cloudflare D1 database

## Database
